# Project summary

**Title:** Service Catalog and Employee Request Automation Portal  
**Platform:** ServiceNow Service Catalog, Record Producers, Flow Designer, ACLs, REST APIs.

Workflow concept: employee submits catalog request → manager approval → approved request routes to fulfillment → status and requester notifications update → optional outbound REST integration exchanges request data.

**Status:** Implementation kit prepared; not proof of a live configured instance. Implement and test in a ServiceNow PDI and capture your own evidence before claiming completed hands-on experience.
